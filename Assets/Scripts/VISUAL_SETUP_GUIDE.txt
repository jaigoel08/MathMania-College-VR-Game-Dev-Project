## 🎯 HOW IT WORKS

### Flow Diagram:

```
1. Player moves mouse
   ↓
2. MouseLook rotates camera
   ↓
3. Player holds Left Mouse Button
   ↓
4. SimpleMouseShooter creates bullet
   ↓
5. Bullet flies from camera center
   ↓
6. Bullet hits target (answer cube)
   ↓
7. Game registers correct/wrong answer
```

## 🎮 CONTROL COMPARISON

### VR Controls (Original):
```
Grab Gun    = Grip Button
Aim         = Move Hand
Shoot       = Trigger Button
```

### Mouse Controls (New):
```
Grab Gun    = Not needed (shoot from camera)
Aim         = Move Mouse
Shoot       = Left Mouse Button
```

## 💡 TWO METHODS EXPLAINED

### METHOD 1: Direct Shooting (Recommended)
```
Camera → Shoot → Target
- Fastest
- Easiest
- No gun pickup needed
- Just point and click
```

### METHOD 2: Gun Pickup (Advanced)
```
Look at Gun → Click to Pickup → Hold Gun → Shoot → Target
- More realistic
- More steps
- Need to find guns first
- More like VR experience
```

**For your multiplication scene: Use METHOD 1!**

## 🆘 COMMON ISSUES & FIXES

### Issue: Can't see crosshair
```
Fix: In SimpleMouseShooter, check ✓ "Show Crosshair"
```

### Issue: Bullets spawn but don't move
```
Fix: Increase "Bullet Speed" to 30 or higher
```

### Issue: Mouse doesn't move camera
```
Fix 1: Click in game window to lock cursor
Fix 2: Check MouseLook is on Main Camera
Fix 3: Press ESC, then click again
```

### Issue: Nothing happens when clicking
```
Fix 1: Make sure bullet prefab is assigned (not "None")
Fix 2: Check console for error messages
Fix 3: Make sure cursor is locked (should be invisible)
```

### Issue: Bullets go through targets
```
Fix: Check targets have Collider components
```
