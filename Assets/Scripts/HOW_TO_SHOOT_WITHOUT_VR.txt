# 🎯 How to Shoot Targets WITHOUT VR - Complete Guide

## Problem
You can't shoot in the multiplication scene because the game requires VR controllers, but you don't have a VR headset.

## Solution
I've created TWO methods for you to shoot without VR:

---

# ⚡ METHOD 1: Direct Camera Shooting (EASIEST - RECOMMENDED)

This method lets you shoot directly from the camera without needing to pick up guns.

## Setup (2 Minutes)

### Step 1: Add Script to Camera
1. Select your **Main Camera** in the scene
2. Click **Add Component**
3. Search for **Simple Mouse Shooter**
4. Add it

### Step 2: Assign Bullet Prefab
1. In the Inspector, find **Simple Mouse Shooter** component
2. Find **Bullet Prefab** field
3. Drag your bullet prefab from Project window
   - Look in Assets/Prefabs or where your bullets are stored
   - Usually named something like "Bullet", "Projectile", etc.

### Step 3: Configure Settings
- **Bullet Speed:** 20-30 (adjust for faster/slower bullets)
- **Shoot Cooldown:** 0.3 (time between shots)
- **Shoot Key:** Mouse0 (left click)
- **Show Crosshair:** ✓ Check this

### Step 4: Test
1. Press **Play**
2. **Hold Left Mouse Button** to shoot
3. Aim with mouse movement
4. Press **ESC** to unlock cursor if needed

## Controls
- **Left Mouse Button (Hold)** = Shoot continuously
- **Mouse** = Aim
- **ESC** = Unlock cursor

---

# 🔫 METHOD 2: Gun Pickup System (More Realistic)

This method lets you pick up the actual gun objects in the scene and shoot with them.

## Setup (5 Minutes)

### Step 1: Update Existing Guns
The guns already have the `shoot.cs` script updated to support mouse!

For each gun in your scene:
1. Select the gun object
2. Find the **shoot** component
3. Make sure these are set:
   - ✓ **Enable Mouse Shooting** (check this!)
   - **Shoot Key:** Mouse0
   - **Shoot Cooldown:** 0.2
   - **Bullet:** (should already be assigned)
   - **Barrel Pivot:** (should already be assigned)

### Step 2: Add Mouse Look to Camera
1. Select **Main Camera**
2. Add Component → **Mouse Look** (script I created earlier)
3. Set **Mouse Sensitivity:** 100
4. Assign **Player Body** (drag your player object)

### Step 3: Add Gun Controller to Player
1. Select your **Player** object
2. Add Component → **Mouse Gun Controller** (script I created earlier)
3. Assign **Player Camera**
4. Set **Pickup Range:** 5

### Step 4: Tag Guns
1. Select all gun objects
2. In Inspector, click **Tag** dropdown
3. If "Gun" tag doesn't exist:
   - Click "Add Tag"
   - Create new tag: "Gun"
4. Apply "Gun" tag to all guns

### Step 5: Test
1. Press **Play**
2. Look at a gun
3. **Left Click** to pick it up
4. **Left Click again** to shoot
5. **Q** to drop gun

## Controls
- **Left Click** = Pick up gun (when looking at it)
- **Left Click** = Shoot (when holding gun)
- **Q** = Drop gun
- **Mouse** = Aim

# 🔧 Troubleshooting

## Can't Shoot (Method 1)
**Problem:** Left clicking doesn't shoot
**Solutions:**
- ✓ Check cursor is locked (press ESC then click to lock)
- ✓ Check bullet prefab is assigned
- ✓ Check bullet speed is not 0
- ✓ Look in console for error messages

## Bullets Don't Hit Targets
**Problem:** Bullets pass through targets
**Solutions:**
- ✓ Check targets have Collider components
- ✓ Check bullet has Rigidbody component
- ✓ Increase bullet speed
- ✓ Check collision layers

## Can't Pick Up Guns (Method 2)
**Problem:** Left clicking on gun doesn't pick it up
**Solutions:**
- ✓ Check guns have "Gun" tag
- ✓ Check guns have Collider
- ✓ Increase pickup range (try 10)
- ✓ Make sure MouseGunController is on player

## Aiming Doesn't Work
**Problem:** Mouse doesn't move camera
**Solutions:**
- ✓ Check MouseLook is on camera
- ✓ Check cursor is locked (click screen)
- ✓ Increase mouse sensitivity
- ✓ Check Player Body is assigned

# ⚙️ Fine-Tuning Settings

## Bullet Speed
- **Too slow (5-10):** Bullets drop, hard to hit
- **Just right (20-30):** Good arc, easy to aim
- **Too fast (50+):** Instant but hard to see

## Shoot Cooldown
- **0.1:** Rapid fire (machine gun)
- **0.3:** Balanced (pistol)
- **1.0:** Slow (sniper)

## Mouse Sensitivity
- **50-75:** Slow, precise (for sniping)
- **100:** Standard (balanced)
- **150-200:** Fast (for action)
